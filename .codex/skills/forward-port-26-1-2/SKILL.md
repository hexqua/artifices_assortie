# 26.1.2へのforward-port

1. [移植ガイド](../../../docs/forward-port-26.1.2.md)で対象機能の仕様差と受け入れ条件を確認する。
2. 26.1.2-mainから作業ブランチを作り、機能に必要な非mergeコミットを依存順に選ぶ。`git cherry-pick -x` で移植元を記録する。
3. 競合は対象版のMinecraft・NeoForge・親MODの配布版に合わせて解決する。休眠IDの読込と、除外連携に依存しない通常経路を保つ。
4. 生成物は対象版のproviderから作り直す。実際の射撃・ドロップ・メニュー操作で確認し、クライアント固有の未確認項目は引き渡す。
5. build・GameTestと差分レビュー後、元SHA、版固有の補正、検証結果を対応付ける。portのローカルコミット許可をリモート操作や通常開発に広げない。
